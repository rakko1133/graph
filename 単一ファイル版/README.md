# 単一ファイル版（配布・持ち出し用）

このフォルダには、アプリを**1ファイルに結合した版（単一ファイル版）**が入ります。

- `graph_onefile.py` … 通常版（全機能）を1ファイルに結合したもの
- `graph_simple_onefile.py` … シンプル版（起動時の表示レベルが「基本」）を1ファイルに結合したもの

## 「分割版」との違い

- **分割版（本体）** = リポジトリ**ルート直下**の `graph_app.py` と各モジュール（`plotter.py`,
  `analysis.py` …）。普段の開発・実行はこちらが本体です。
- **単一ファイル版（このフォルダ）** = 分割版の全モジュールを結合した**生成物**。配布や持ち出しに使います。

## 生成物であること（git 管理外）

`graph_onefile.py` / `graph_simple_onefile.py` は**ビルドで自動生成される成果物**で、
git では管理していません（本体を1行直すだけで1万行超の差分が出るため）。この README だけが
git に残ります。必要な人は CI の artifact から取得するか、下記でローカル生成してください。

## 再生成のしかた

リポジトリのルートで:

```bash
python tools/build_onefile.py          # → 単一ファイル版/graph_onefile.py
python tools/build_simple_onefile.py   # → 単一ファイル版/graph_simple_onefile.py
```

起動は、ルートの **`1ファイル版_起動.bat`** / **`シンプル版_1ファイル_起動.bat`** を
ダブルクリック（無ければ自動でビルドしてから起動します）。
