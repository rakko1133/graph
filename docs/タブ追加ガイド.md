# タブの追加ガイド（拡張のしかた）

このアプリの左側の解析タブ（データ / オシロ・解析 / 高度解析 / 統計解析）は
**差し込み式（プラグイン）**です。新しい機能が欲しくなったら、**タブのファイルを
1つ作り、メイン（`graph_app.py`）冒頭に import を1行足すだけ**で追加できます。
（描画・設定・各 Mixin などコア側の他の場所は触りません。）

## 仕組み

- タブ1枚 = `TabPlugin`（`graph_app_common.py`）を継承したクラス1つ
- `register_tab(...)` で登録すると、起動時に `GraphApp` が `registered_tabs()` を
  読んでタブを並べる
- 表示レベル（基本／標準／全部）・並び順・タイトルは、プラグインが自分で宣言する
- 設定検索（Ctrl+F）の索引・表示レベルの出し入れにも**自動で乗る**

内蔵の4タブも同じ仕組みで登録されています（`graph_app.py` 末尾の `BUILTIN_TABS`）。
中身の組み立ては各 Mixin のメソッドに委譲しているだけなので、挙動は元と同じです。

## 最短の例

新しいファイル（例: `graph_tab_mytool.py`）を作り、次を書きます。

```python
from graph_app_common import TabPlugin, register_tab, QtWidgets


class MyToolTab(TabPlugin):
    key = "mytool"          # 一意な識別子。ドックの objectName は "dock_mytool"
    title = "5. 自作ツール"   # タブ見出し
    order = 50               # 小さいほど左（上）。内蔵4タブは 10/20/30/40
    min_level = "全部"        # このタブが現れる最小の表示レベル（基本 < 標準 < 全部）

    def build(self, app):
        """タブの中身を返す。app は GraphApp インスタンス。"""
        w = QtWidgets.QWidget()
        lay = QtWidgets.QVBoxLayout(w)
        btn = QtWidgets.QPushButton("いま選んでいる系列を解析")
        btn.clicked.connect(lambda: self._run(app))
        lay.addWidget(btn)
        lay.addStretch(1)
        return w

    def _run(self, app):
        got = app.analysis_xy_or_warn()   # 既存メソッドがそのまま使える
        if got is None:
            return
        t, y, label = got
        # ここで自由に計算する。結果を新しいデータとして足すなら:
        # app.register_dataset("MyTool: " + label, dataframe)
        app.notify(f"{label} を解析しました（{len(y)} 点）", "ok")


register_tab(MyToolTab())
```

これを **`graph_app.py` から import** すれば登録されます。内蔵タブと同じく、
`graph_app.py` 冒頭の import 群に1行足してください（この import が走った時点で
モジュール末尾の `register_tab(...)` が実行され、タブが登録されます）:

```python
from graph_tab_mytool import MyToolTab   # 自作タブ（import で register_tab が走る）
```

`graph_app.py` は「メイン1ファイル（GUIの土台）」で、`graph_tab_*.py` が
「1タブ=1ファイル」です。メインがタブを import することで、そのタブが有効化されます。

## `build(app)` の中で使えるもの（`app` は `GraphApp`）

| やりたいこと | 呼ぶもの |
|---|---|
| いま選んでいる解析対象の (t, y, ラベル) を取る | `app.analysis_xy_or_warn()` |
| 系列(ファイル, 列)から数値配列を取る | `app.series_xy(fl, col)` |
| 計算結果を新しいデータとして追加する | `app.register_dataset(名前, dataframe)` |
| グラフを描き直す | `app.draw_graph()` |
| 画面内に通知を出す（モーダルにしない） | `app.notify(文, "info"/"ok"/"warn"/"error")` |
| ステータスバーへ一行出す | `app._set_status(文)` |
| 選択中のY系列を列挙する | `app._selected_series_items()` |

## グラフに描く／設定を保存する（任意の拡張口）

`build(app)` に加えて、プラグインに**次のメソッドを定義するだけ**で、コア
（`graph_app.py`）を1行も触らずに機能を広げられます。

```python
class MyToolTab(TabPlugin):
    # ... key/title/order/min_level と build(app) は前述どおり ...

    def draw_overlay(self, app, ax):
        """app.draw_graph() のたびに呼ばれる。メイングラフ ax へ重ね描きできる。"""
        for i in range(self.spin.value()):
            ax.axvline(i, color="magenta", linestyle=":")

    def collect_config(self, app):
        """このタブの設定を保存用 dict で返す（JSON化できる値だけ）。"""
        return {"n": self.spin.value()}

    def apply_config(self, app, cfg):
        """保存した dict から設定を復元する。"""
        self.spin.setValue(int(cfg.get("n", 3)))
```

- **`draw_overlay(app, ax)`** … メイングラフへ注記・目印・基準線などを重ねられる
  （再描画のたびに引き直される）。トグル等を変えたら `app.draw_graph()` を呼ぶ。
- **`collect_config(app)` / `apply_config(app, cfg)`** … このタブの設定が、他の設定と
  一緒に**終了時に自動保存・起動時に自動復元**される（保存先はタブの `key` 名前空間）。

いずれも**任意**（定義しなければ何も起きません）。これで「グラフ上に描く」
「設定が残る」タイプの機能も、タブファイル1つ（＋import 1行）で足せます。

## 単一ファイル版に含めるには

`単一ファイル版/graph_onefile.py` / `単一ファイル版/graph_simple_onefile.py` に自作タブも入れたいときは、
`tools/build_onefile.py` の `ORDER` に自作タブのファイル名を
（`"graph_tab_*.py"` の並び、`"graph_app.py"` より前に）足し、`INTERNAL` にも
モジュール名を足してから再ビルドします。内蔵タブと同じ扱いで結合されます。

## 表示レベルとの関係

`min_level` は「そのタブが最初から見える表示レベル」です。

- `"基本"` … 基本／標準／全部 のすべてで表示（＝常に見える）
- `"標準"` … 標準・全部で表示
- `"全部"` … 全部のときだけ表示

基本・標準で隠れているタブの中の設定も、**Ctrl+F（設定を検索）で名前を入れれば
表示レベルを自動で上げてそこまで移動**します（機能は隠れるだけで失われません）。
