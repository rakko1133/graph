# コンポーネント図（PlantUML 版）

本アプリのコンポーネント構成を PlantUML で記述したものです。仕様書
[仕様書.md](仕様書.md) の「5.1 システム構成図（コンポーネント図）」にある
Mermaid 版と同じ 7 層構成を表します。

- **Obsidian** では、PlantUML プラグイン（`obsidian-plantuml` など）を入れると
  下の ` ```plantuml ` ブロックが図として描画されます。
- **描画バックエンド**: PlantUML はレンダリングに PlantUML サーバまたはローカルの
  Java＋`plantuml.jar` が必要です。既定は公開サーバ（plantuml.com）へ図のテキストを
  送って描画するため、非公開で使うならローカルサーバ／jar の設定を推奨します。
- **GitHub** はこの `plantuml` ブロックを図として描画しません（コードとして表示）。
  GitHub で図を見たい場合は仕様書の Mermaid 版を参照してください。

```plantuml
@startuml
title グラフ・オシロ解析ツール — コンポーネント図

package "起動口" {
  [通常版]
  [シンプル版]
  [単一ファイル版]
  [Excel出力]
}
package "GUIシェル (GraphApp)" {
  [フレーム系 Mixin]
  [graph_app_common]
}
package "解析タブ (TabPlugin)" {
  [データ]
  [オシロ/解析]
  [高度解析]
  [統計解析]
  [しきい値]
}
package "ドメインロジック (Qt非依存)" {
  [data_loader]
  [plotter]
  [analysis]
  [mathchan・advanced]
  [datasci]
  [batch_render]
}
package "Excel出力 (excel_chart)" {
  [export]
  [spec・mapping]
  [com_engine]
  [openpyxl_engine]
}
package "外部ライブラリ" {
  [PySide6 / Qt6]
  [matplotlib]
  [NumPy・pandas・SciPy]
}
package "永続化・基盤" {
  [config_io]
  [QSettings]
  [applog]
  [jp_font]
}

[通常版] --> [フレーム系 Mixin]
[シンプル版] --> [フレーム系 Mixin]
[単一ファイル版] --> [フレーム系 Mixin]
[Excel出力] --> [export]
[フレーム系 Mixin] --> [データ] : register_tab
[フレーム系 Mixin] --> [plotter]
[オシロ/解析] --> [analysis]
[高度解析] --> [mathchan・advanced]
[統計解析] --> [datasci]
[data_loader] --> [NumPy・pandas・SciPy]
[plotter] --> [matplotlib]
[analysis] --> [NumPy・pandas・SciPy]
[フレーム系 Mixin] --> [PySide6 / Qt6]
[batch_render] --> [export]
[export] ..> [data_loader] : data_loader 再利用
[フレーム系 Mixin] --> [config_io]
@enduml
```
